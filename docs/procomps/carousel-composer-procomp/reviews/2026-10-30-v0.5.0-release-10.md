## Findings

#### F-01 — A controlled host that rejects a pan

- **Severity:** 🔹 · **Dimension:** 12 · **Location:** `parts/main-preview.tsx` (pending offset)
- **Observed:** the dragged position stays on screen until the host's `value` carries it; a host that never accepts it
  keeps showing the dragged position (no reject signal). Documented (guide §7b).
- **Fix / owner:** on request (a reject callback or a timeout, ~10 lines).

#### F-02 — `exportMeta` overlay coordinates after an off-centre cut

- **Severity:** 🔹 · **Dimension:** 12 · **Location:** `features/editing/parts/edit-panel.tsx` `cropBlob`
- **Observed:** after a panned edit the blob is cut from the full export; `exportMeta`'s overlay coordinates are not re-based
  (`editorState` is unaffected; re-edit works). A second JPEG encode for an off-centre cut.
- **Fix / owner:** carousel-composer-editing, next minor, if a host reads `exportMeta` overlays.

#### F-03 — Small targets

- **Severity:** 🔹 · **Dimension:** 6 · **Location:** `parts/rail-thumb.tsx`
- **Observed:** the reorder pair is 16 × 16 px on narrow thumbs (spacing-exempt: no overlaps, measured at 9:16).
- **Fix / owner:** on request (reply note).

#### F-04 — Unmodified Done is not guarded

- **Severity:** 🔹 · **Dimension:** 12
- **Observed:** Done with no change exports nothing and reports no busy period, so Escape right after it closes a host
  dialog (0.4.0 behaviour; nothing is in flight). By design.
- **Fix / owner:** none.
