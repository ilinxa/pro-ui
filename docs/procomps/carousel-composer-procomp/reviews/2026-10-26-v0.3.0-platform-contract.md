### Rotating dimension

- **Chosen:** the install graph under the feature-slicing rule (locked decision 5): a plain install must contain no
  media-editor file, the add-on must restore today's editing, and the one dependent that edits (content-composer) must
  keep working.
- **Why:** CC1 is the platform's first ask, and a feature slice that leaks back into the base (or a dependent that
  silently loses editing) is invisible to every unit test.
- **Verified?** yes — `install-graph` test (no non-feature file imports media-editor; no shipped `export … from
  "@/registry/…"`); the registry roster generated from the folder; the heavy-dependency gate (fixed so a feature slice
  may reach a heavy item while an edge INTO the slice still counts); the install matrix incl. the base alone (negative
  path) and content-composer.
