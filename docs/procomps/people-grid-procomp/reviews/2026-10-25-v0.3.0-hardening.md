## Findings (residual, at GATE 3)

#### R-01 — Initials fallback contrast (pre-existing)

- **Severity:** 🔸 · **Dimension:** 3
- **Observed:** `text-primary` on `bg-primary/10` measures 1.56:1 in light mode (axe, Chromium). Unchanged since 0.1;
  the initials are `aria-hidden` (the name is the heading), so it is legibility, not naming. Lime text on light
  surfaces is a library-wide token question.

#### R-02 — Budget raised 15 → 18 KB

- **Severity:** 🔹 · **Dimension:** 9
- **Observed:** 16.18 KB built (estimate was 12.7; JSDoc + grapheme / locale helpers). 10 % headroom.

#### R-03 — Empty space in the actions row does not navigate

- **Severity:** 🔹 · **Dimension:** 2
- **Observed:** the `relative z-10` actions row spans the card width, so a click beside the buttons hits the row, not
  the card link. The contract (slots never navigate) holds.
