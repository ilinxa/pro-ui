## Findings (residual, at GATE 3)

U4's 18 confirmed findings are fixed or gated (U5 proved the install claim); 4 were dropped with reasons. What remains:

#### F-01 — An `AppSidebarTrigger` outside the sidebar cannot read `labels`

- **Severity:** 🔸
- **Dimension:** a11y / C2
- **Location:** `parts/sidebar-nav-trigger.tsx`
- **Observed:** the usual layout (hamburger in the app header, a sibling of the sidebar) gets no context; its name falls back to English unless the consumer passes `aria-label`. Documented in the guide, usage and meta, but the default is still English.
- **Suggested fix:** a `labels` (or `label`) prop on the trigger, or expose the resolved labels on the handle `controls` points to.

#### F-02 — Collapsed rail + collapsible section: arrow keys can land on a header with no DOM node

- **Severity:** 🔸
- **Dimension:** a11y
- **Location:** `lib/flatten-entries.ts` + the collapsed-rail branch of `parts/sidebar-nav-section.tsx` (pre-existing; both finders parked it)
- **Observed:** the keyboard sequence still lists the section header, which the rail branch does not render; focus then has no target and every row is `tabIndex=-1`.
- **Suggested fix:** omit collapsible headers from the keyboard sequence while the rail is collapsed (or render a focusable rail header).

#### F-03 — Badge name announces the raw count while the pill shows "9+"

- **Severity:** 🔹
- **Dimension:** a11y (WCAG 2.5.3)
- **Location:** `parts/sidebar-nav-row.tsx`
- **Observed:** by the request's spec (`itemWithBadge(label, value: number)` so the host can pluralize), the name says 25 where the pill says 9+; the name also replaces a visible shortcut/accessory. Documented.
- **Suggested fix:** pass the formatted display string as a third argument and let hosts choose; confirm with the platform.

#### F-04 — Served item carries no version; no new-york consumer smoke

- **Severity:** 🔸
- **Dimension:** 9
- **Location:** `public/r/app-sidebar.json`; smoke harness (base-nova consumer)
- **Observed:** C10's version stamp is not in any served item (R10), and both installs ran against a base-nova consumer while the platform uses new-york (R12). The drawer-width fix was reasoned for both sheet styles (finder evidence) but only observed on nova.
- **Suggested fix:** Part 1 R10 / R12.

#### F-05 — `state={useAppSidebarState()}` silently ignores `isCollapsed`

- **Severity:** 🔹
- **Dimension:** API
- **Location:** `app-sidebar.tsx` (`finalCollapsed = externalState?.collapsed ?? …`)
- **Observed:** documented in the guide's gotchas; no dev warning; the hook has no controlled options (parked since U0).
- **Suggested fix:** dev-warn on the combination; add controlled options to the hook on demand.
