### Rotating dimension

- **Chosen:** the publish state machine (details step, cancel, retry, close, reset, re-entrancy).
- **Why:** the platform's composers drive publish from their own stores and uploaders; the U4 finder showed the flow
  state outlived close / reset and raced on Cancel → Publish.
- **Verified?** yes — run-token + one-flow-at-a-time tests, close / reopen / success-consumes-draft tests (real editor
  where the editor matters), browser re-verify of Tab wrap, Escape, focus targets, draft consumption, contrast.
