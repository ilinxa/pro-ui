## What changed

- **media-editor 0.4.0:** the documented nested `labels` prop works — a normalizer maps nested keys onto
  the internal flat shape (flat keys win, so story-composer's output is byte-identical). New additive
  `overlay?: ReactNode`, rendered as the last child of the editor surface (inside the dialog content in
  dialog presentation). Every warn-only handle member carries `@notImplemented` on its type; the inert
  `labels.publish` / `labels.empty` groups are tagged and dev-warn. Version pins removed from code
  strings, comments, JSDoc and the guide; the guide no longer claims undo/redo work.
- **story-composer 0.5.0:** the publishing overlay (default or `renderPublishingOverlay`) goes through
  `overlay`, so it renders inside the modal and Retry / Cancel are clickable. Minor, not patch: it
  requires media-editor ≥ 0.4.0.
