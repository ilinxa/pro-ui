## Findings

#### F-01 — Tap targets on a phone

- **Severity:** 🔹 · **Dimension:** 6 · **Location:** tool chips (`media-editor.tsx` chip row)
- **Observed:** icon-only chips are 38 × 30 px (browser F-6) — under 44 px, spacing-exempt under WCAG 2.5.8.
- **Fix / owner:** media-editor, next minor if the platform asks (reply note).

#### F-02 — Base UI and WebKit not exercised here

- **Severity:** 🔹 · **Dimension:** 12
- **Observed:** `classifyCloseReason` matches Base UI reason strings by name; Base UI is not installed in this repo. Container
  query units, the press record on a touch backdrop and the dark subtree were measured in Chromium only.
- **Fix / owner:** the platform's pass (reply asks for it); re-test on their report.
- **Update 2026-10-31:** Base UI half closed on our side. The platform runs `radix-ui` and has no `@base-ui/react`, so its
  pass cannot cover this; checked against `@base-ui/react` 1.4.1 source instead: `internals/reason-parts.js` defines
  `outside-press` / `escape-key`, `floating-ui-react/hooks/useDismiss.js` raises them, and `DialogRoot.d.ts` types
  `onOpenChange(open, eventDetails)`. That is a source check, not a browser run. WebKit half stays with the platform.

#### F-03 — `renderTopBar` / `overlay` render with dark tokens in a fixed-aspect dialog

- **Severity:** 🔹 · **Dimension:** 1 · **Location:** root `dark` class (F-3 fix)
- **Observed:** intended (the surface is black), but a host's top bar styled for the page theme changes look.
- **Fix / owner:** documented (guide, CHANGELOG, migration row, reply); no code change.
