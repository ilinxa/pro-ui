### Rotating dimension

- **Chosen:** truncation vs wrapping measured in a real engine.
- **Why:** jsdom has no layout; "truncates" and "wraps" are only claims there.
- **Verified?** yes — default mission row `scrollWidth > clientWidth` with `title`; with `wrap` the 193-character
  mission is four lines tall and has no `title`; the sandbox's seven rows still truncate, now with `title`; the
  production build logs no `[info-list]` warning.
