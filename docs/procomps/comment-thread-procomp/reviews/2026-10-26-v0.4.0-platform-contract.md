### Rotating dimension

- **Chosen:** realtime + optimistic correctness under the platform's own wiring (their broadcast includes the sender's
  socket, so the echo can beat `onAddComment`; `clientId` echoed once they adopt 0.4.0).
- **Why:** this is where today's code duplicated rows, and the shape the platform will run in production.
- **Verified?** yes — echo before / after the resolve, with and without `clientId`, with a Comment and with a void
  result (A1 was found here); two accepts in one tick (A2); a delta for a child of a parent that arrived in the same
  tick (A2b); latest-wins per target; rollback of add / like / reaction / delete / edit; no unhandled rejection from
  any path, including throwing host callbacks (A9).
