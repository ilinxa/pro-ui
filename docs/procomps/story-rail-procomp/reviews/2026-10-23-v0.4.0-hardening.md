## Findings (residual, at GATE 3)

The 23 U4 findings are closed in the loop file (20 fixed, 3 dropped with evidence, 13 regression tests added and
two of them falsified by re-introducing the bug). The rows below are what remains true **after** the fixes.

#### F-01 — Served item carries no version (C10)

- **Severity:** 🔸
- **Dimension:** 9
- **Location:** `public/r/story-rail.json` (generated)
- **Observed:** the consumer's C10 asks the served item to carry the component version; no item does yet. Convention decision pending (R10: header in served `content` vs `meta` field vs component-versions).
- **Suggested fix:** Part 1 R10, registry-wide. Tell the platform team it is not in this ship.

#### F-02 — Real-Embla behaviour is proven only by the browser pass, not by an automated test

- **Severity:** 🔸
- **Dimension:** 12
- **Location:** `__tests__/*` (Embla mocked)
- **Observed:** snap mapping, `slidesInView` page math, `watchFocus`, `reInit` listener survival are verified by the U5 Playwright run against `next start`, which lives in the session scratchpad, not the repo. A regression there would pass CI.
- **Suggested fix:** a `tests/e2e` Playwright spec for the story-rail docs page (arrows, Tab-scroll, RTL) under Part 1 R9 (test harness).

#### F-03 — No new-york-style consumer smoke

- **Severity:** 🔹
- **Dimension:** 9
- **Location:** smoke harness (base-nova consumer)
- **Observed:** the platform uses shadcn **new-york**; both installs ran against a base-nova consumer. Story-rail's only primitive is `avatar` (style-specific source), so the residual risk is small.
- **Suggested fix:** Part 1 R12 (new-york consumer on CLI 3.8.x + 4.x).

#### F-04 — `exactOptionalPropertyTypes` errors in shipped files

- **Severity:** 🔹
- **Dimension:** 12
- **Location:** `story-thumbnail.tsx`, `story-rail.tsx`, `dummy-data.ts` (finder-2 parked list)
- **Observed:** `X | undefined` passed to optional props. Repo-wide parked flag (525 errors at last measure); the platform's tsconfig does not enable it.
- **Suggested fix:** with the repo-wide burn-down (readiness config "consumer-strict flags" backlog).

#### F-05 — Direction resolved once after mount

- **Severity:** 🔹
- **Dimension:** a11y/i18n
- **Location:** `hooks/use-rail-environment.ts`
- **Observed:** an app that flips `<html dir>` at runtime without remounting keeps the old Embla direction; documented ("pass `dir`"). A `MutationObserver` would close it.
- **Suggested fix:** revisit if the platform's language switch does not remount; owner story-rail next minor.
