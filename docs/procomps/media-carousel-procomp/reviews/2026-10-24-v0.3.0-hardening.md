### Rotating dimension

- **Chosen:** runtime behaviour that jsdom cannot show (inert hit-testing, Embla's drag/click guard, real video playback, Tailwind direction variants).
- **Why:** three of the contract's items (neighbour click, in-view pause, RTL visuals) are browser behaviour; the unit suite runs a fake Embla.
- **Verified?** yes — Playwright on `next start`: a click on the peeking neighbour lands on its wrapper and scrolls to it; a drag that starts on the neighbour does not count as a click; an inherited `dir="rtl"` lays slides right-to-left, mirrors ArrowLeft, rotates the chevrons and flips the fades; the active video plays and pauses when the page scrolls it out of view; `--media-carousel-inactive-blur: 0px` computes to `blur(0px)`; `"fine-pointer"` buttons render on desktop and not under mobile emulation; the error tab recovers the image once. The run also found a dead sample-video URL in the shipped fixtures (404 since before 0.3) — replaced.

## Findings (residual, at GATE 3)

The 8 U4 rows are closed in the loop file (all CONFIRMED; F1–F7 fixed, F8 = regression tests, falsified by
reverting the F1 and F2 fixes: 5 tests fail). The rows below remain true **after** the fixes.

#### R-01 — Browser proof lives in the session scratchpad

- **Severity:** 🔸 · **Dimension:** 12
- **Observed:** neighbour click, drag guard, video pause and RTL visuals are proven by a Playwright run against `next start` that is not in the repo.
- **Suggested fix:** a `tests/e2e` spec for the media-carousel docs page, with engagement-bar's R-01.

#### R-02 — Swipe on a real touch device not exercised

- **Severity:** 🔸 · **Dimension:** runtime
- **Observed:** mobile emulation checked layout and the hidden nav buttons only; a finger swipe and a tap on the peeking neighbour were not driven.
- **Suggested fix:** the platform's device check on their post card.

#### R-03 — A refreshed video restarts from 0

- **Severity:** 🔹 · **Dimension:** request (MC4)
- **Observed:** resume-at-time needs `VideoPlayer` support (request VP4).
- **Suggested fix:** video-player's loop (next), then pass the time through.

#### R-04 — Inherited LTR inside an RTL page needs `dir` on the carousel

- **Severity:** 🔹 · **Dimension:** i18n
- **Observed:** Tailwind's `rtl:` matches any descendant of `[dir="rtl"]`; the explicit-prop case is overridden (F5), a `dir="ltr"` wrapper alone is not. Direction is also read once after mount (as story-rail F-05). Both documented in the guide.

#### R-05 — post-card forwards none of the new props

- **Severity:** 🔹 · **Dimension:** dependents
- **Observed:** post-card renders the default gallery (square, English labels, no `locale`, no `onMediaError`); unchanged and correct, but a post-card host cannot reach MC1/MC3/MC4/MC5 without `renderMedia`.
- **Suggested fix:** post-card's Part 3 loop.

#### R-06 — Arrow keys inside slide content also move the carousel

- **Severity:** 🔹 · **Dimension:** a11y (pre-existing)
- **Observed:** the region's `onKeyDown` sees bubbled keys from the video controls.
- **Suggested fix:** ignore keys from interactive descendants; with video-player's loop.

#### R-07 — Size headroom 3 %

- **Severity:** 🔹 · **Dimension:** 9
- **Observed:** 53.27 KB of 55. The next addition needs a budget decision.
