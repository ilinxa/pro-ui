## Findings (max 5)

Findings surfaced during the loop (C3 spot-check + C5 fresh-finder pass) — all resolved pre-review:

#### F-01 — Stagger flash: `animate-in` fill-mode defaults to none
- **Severity:** ⚠️ High → fixed
- **Dimension:** Verification / design system
- **Location:** `empty-state.tsx` (delayStyle)
- **Observed:** delay-staggered elements render visible during their delay, snap to opacity 0, animate back.
- **Fix applied:** inline `animationFillMode: "both"`; verified live post-fix.

#### F-02 — `action={false}` mounts an empty actions row
- **Severity:** 🔸 Medium → fixed
- **Dimension:** Public API
- **Location:** `empty-state.tsx` (renderAction / hasActions)
- **Observed:** `action={cond && {…}}` idiom with cond=false type-checks and rendered an empty margin+gap row.
- **Fix applied:** falsy-boolean/empty-string guard in `renderAction`; I2 re-verified live (0 interactive elements).

#### F-03 — `media` wrapper force-`aria-hidden` hid consumer alt text
- **Severity:** 🔸 Medium → fixed
- **Dimension:** Accessibility
- **Location:** `empty-state.tsx` (media branch)
- **Observed:** meaningful illustration semantics unconditionally hidden from AT.
- **Fix applied:** aria-hidden removed from the media branch; contract documented in guide.

#### F-04 — Plan/code drift on sm tile radius
- **Severity:** 🔹 Low → resolved as doc-sync
- **Dimension:** Planning docs
- **Observed:** plan said `rounded-2xl` all sizes; code ships `rounded-xl` at sm (proportionally correct).
- **Fix applied:** plan visual spec updated to document the sm refinement.
