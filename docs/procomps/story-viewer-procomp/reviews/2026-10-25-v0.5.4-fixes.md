## Findings

#### F-01 — CLI 3.8.5 aborts `story-viewer-fixtures` added after the base

- **Severity:** 🔸
- **Dimension:** 9
- **Observed:** see the smoke table. Pre-existing (0.5.3 identical), specific to story-viewer on 3.8.5.
- **Suggested fix:** root-cause the 3.8.5 comparison (only `story-viewer.tsx` triggers it); until then document "add the
  fixtures item alone, or both items in one command".

#### F-02 — a host pause set while a layer is open is overridden when it closes

- **Severity:** 🔹
- **Dimension:** behaviour
- **Observed:** the layer restore snapshot is taken when the first layer opens (U4-7). Needs the SV4 pause-reason set.

#### F-03 — non-modal layers don't contain focus; late-mounting siblings behind a sheet aren't inert

- **Severity:** 🔹
- **Dimension:** a11y
- **Observed:** the viewers list and link drawer are non-modal by design (no trap; focus return holds); a sibling that
  mounts while a sheet stays open escapes the `inert` pass (U4-8, B-2, B-3).

#### F-04 — a video that errors mid-play restarts the bar from 0 on the timer

- **Severity:** 🔹
- **Dimension:** behaviour
- **Observed:** U4-9; seeding the timer needs an option on the exported progress hook (not in a patch).

#### F-05 — dark theme: the reply pill is nearly invisible on a bright photo (pre-existing)

- **Severity:** 🔹
- **Dimension:** visual
- **Observed:** B-6.
