## Findings (residual, at GATE 3)

The 18 U4 rows are closed in the loop file (15 fixed, 3 dropped with evidence; 20 regression tests, falsified by
reverting four fixes). The rows below remain true **after** the fixes.

#### R-01 — Browser-only proof lives in the session scratchpad

- **Severity:** 🔸 · **Dimension:** 12
- **Observed:** the portalled picker's real direction, the optimistic rollback in a real browser and the visual RTL layout are proven by a Playwright run against `next start` that is not in the repo.
- **Suggested fix:** a `tests/e2e` spec for the engagement-bar docs page (RTL picker keys, rollback, locale), alongside story-rail's F-02.

#### R-02 — Long-press + page scroll not exercised on a touch device

- **Severity:** 🔸 · **Dimension:** a11y / runtime
- **Observed:** `touch-manipulation`, the `pointercancel` path and the context-menu guard are proven in jsdom and reasoned against the spec; no real touch run.
- **Suggested fix:** the platform's device check on their post card, or a Playwright mobile-emulation spec with `hasTouch`.

#### R-03 — Picker dialog and its group share one name

- **Severity:** 🔹 · **Dimension:** a11y
- **Observed:** "Pick a reaction" names both the popover dialog and the inner `role="group"` (U4 G8). Kept because the standalone `ReactionPicker` needs its group name.
- **Suggested fix:** let `ReactionPicker` omit its group label when embedded.

#### R-04 — Direction read once after mount

- **Severity:** 🔹 · **Dimension:** i18n
- **Observed:** a runtime `<html dir>` flip without a remount keeps the old arrow-key direction; documented (pass `dir`). Same as story-rail F-05.

#### R-05 — story-viewer's inline type copy lags 0.5.0

- **Severity:** 🔹 · **Dimension:** dependents
- **Observed:** `StoryEngagementAction` has no `disabled` / `hidden` / `start` / `end` / `null`; still a valid subset (compiles, renders). Its reaction total is now withheld because it passes no `totalCount` (pair rule).
- **Suggested fix:** story-viewer's Part 3 loop.

#### R-06 — post-card forwards no `locale` / `formatCount`; `likersMoreLabel` is still a template

- **Severity:** 🔹 · **Dimension:** dependents / i18n
- **Suggested fix:** post-card's Part 3 loop (then drop LikersStrip's `moreAriaLabelTemplate` alias and its `template-ok` escape).

#### R-07 — Switching an action between controlled and uncontrolled leaves stale internal counts

- **Severity:** 🔹 · **Dimension:** robustness
- **Observed:** documented anti-pattern since 0.1; Defense 2 mirrors only `viewerReaction`.
- **Suggested fix:** a dev-warning on a mode switch (the scaffold's hook already does this).
