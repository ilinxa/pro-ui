## Findings

#### F-01 — The browser found what jsdom could not (W1–W2)

- **Severity:** ⚠️ (closed) · **Dimension:** 12 · **Location:** `parts/reaction-action.tsx`
- **Observed:** U4 fix A3 moved the primary-tap flag to the capture phase and cleared it in a microtask; every jsdom
  test passed while Chromium opened the picker on every primary tap (microtask checkpoint between React's capture and
  bubble listeners). The hover hand-back also closed the picker (focus-outside dismissal).
- **Fix / owner:** fixed in this release (task-timed flag; ignore the self-caused close); both tests model the browser
  behaviour. Lesson recorded in the decision file.

  still passes.
- **Fix / owner:** none needed; revisit if story-viewer adopts EB-2 (release 9, story-viewer 0.7.0).
